## 任务要求

为以下知识点创作讲解视频的分镜脚本。请输出“可直接还原画面”的工程化分镜，不允许概括性描述。

必须严格输出结构化字段（与 schema 对齐）：

1. 每个 scene 必须包含：`scene_index`、`title`、`layout`、`description`、`animation_notes`、`narration`、`subtitles`
2. `layout` 仅允许两种：`left_right`（左右布局）或 `center`（居中布局）
   - **左右布局时，左边只能是文字，右边为动画**
3. `subtitles` 为字符串数组，每一行字幕：
   - 不能超过 25 个字
   - 最后一个字不能是标点符号（如 `，` `。` `！` `？` `；` `：` `、`）
4. `description` 必须包含完整画面文案与视觉信息（包括画面文字、公式、标签、标题、位置关系），不能写“展示概念/讲解原理”等泛化语句
5. `animation_notes` 必须包含可执行的动画细节（时间顺序、对象变化、运动轨迹、转场方式），确保仅靠文本即可还原镜头
6. `narration` 必须是完整可播报文案，不能只写摘要
7. `description`、`animation_notes`、`narration` 必须使用 YAML 多行块格式 `|` 输出；这些字段内容里经常包含冒号、比例、公式，例如 `2:1`，禁止写成未加引号的单行 YAML 值
8. `subtitles` 的每个数组项必须用引号包裹，避免冒号或公式导致 YAML 解析失败
9. 不要输出 `duration_seconds`、`total_duration_seconds` 或其他固定时长字段，避免后续脚本为了填满预设时长生成空白段
10. 如果知识点中包含 `[原始任务]`、`[图片语义重建]`、`[本轮用户指令]`、`[上一版视频内容摘要]` 等结构化上下文：
   - 必须以 `[原始任务]` 和 `[图片语义重建]` 作为题目来源，不得自行替换题目
   - `[本轮用户指令]` 是对本次视频的修改要求，需要优先满足
   - `[上一版视频内容摘要]` 只能作为文本参考，用于理解上一版讲解顺序、旁白和画面结构
   - 禁止要求、假设或声称读取视频 URL、MP4、归档地址、manifest 地址；你只能基于上下文里的文本摘要创作
11. 如果涉及立体几何、空间向量、二面角、棱柱、棱锥、长方体等内容：
   - 必须在相关 scene 中输出 `geometry_render_mode: oblique_projection`
   - 必须在 `description` 中写明“画面采用 2D 斜二测/教材示意图，不使用 3D 旋转镜头”
   - 必须描述几何体类型、顶点标签、边长比例、角度、特殊点、中点关系
   - 必须描述哪些边为可见实线、哪些边为遮挡虚线
   - 必须描述每页需要高亮的线段、平面、向量或角
   - `animation_notes` 只能描述 2D 淡入、描边、高亮、颜色变化、平面半透明覆盖等操作，禁止描述相机旋转、3D 模型旋转、三维坐标轴旋转

## 讲解节奏说明

- 封面打招呼 + 正式讲解 + 结束语
- 苏格拉底式讲解
- **如果用户要求为解题，正式讲解的第一页必须为完整原题展示，不得修改题目表述**
- **如果涉及立体几何讲解，描述几何图形时，必须把关键比例也描述出来，比如边的比例，尽可能做到靠文字就能还原几何图形**
- **立体几何必须使用 2D 斜二测/教材示意图表达，不得要求 Manim 真 3D 渲染或相机运动**
