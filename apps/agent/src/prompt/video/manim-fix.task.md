## 立体几何修复策略（必须遵守）

遇到以下问题时，应按 2D 伪投影合同修复：

1. `BaseScene` 中使用 `ThreeDAxes`、`Dot3D`、`Arrow3D`、`Cube`、`Surface`：删除 3D API，改用 `Line`、`DashedLine`、`Dot`、`Polygon`、`Arrow`。
2. 三维坐标直接传给 2D 图元：增加 `_project_3d_to_2d(...)`，所有点先投影再绘制。
3. 上下底面重合、侧棱消失、标签挤压：重新定义斜二测投影方向，确保高度映射到屏幕 `UP`，深度映射到右上或左上斜向。
4. 需要坐标系说明：用左侧文字或普通 2D 辅助箭头表达，不使用 `ThreeDAxes`。
5. 需要法向量或二面角高亮：用投影后的 2D 线段、箭头和半透明平面表达。
6. 如果出现高亮点、辅助线、平面与主体图错位，优先检查是否在 `self.add_animation(..., side=...)` 之后才追加到主体 `VGroup`；修复时应把这些对象提前创建并加入主体图，再用透明度控制出现。
7. 如果特殊点位置不稳定或与题意不符，优先改为由端点关系计算，例如中点用两个端点平均得到，再统一投影。
